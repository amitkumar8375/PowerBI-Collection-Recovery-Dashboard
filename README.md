# 📊 Power BI Collection & Recovery Dashboard

An interactive Power BI dashboard designed to analyze collection performance, repayment amounts, outstanding amounts, recovery percentage, executive performance, and monthly collection trends.

## 📌 Dashboard Preview

![Collection Analysis Dashboard](Screenshot%202026-08-19%20142905.png)

## 🎯 Project Objective

The objective of this project is to transform collection data into an interactive dashboard that helps monitor repayment performance, outstanding amounts, collection efficiency, and executive-level performance.

## 📈 Key KPIs

- Total Cases
- Total Repayment Amount
- Outstanding Amount
- Collection %
- Closed Cases
- Recovery %

## 📊 Dashboard Analysis

- Collection Amount by State
- Cases by Status
- Monthly Collection Trend
- Executive Performance
- Collection by Executive
- Repayment and Collection Amount Analysis

## 🛠️ Tools & Technologies

- Power BI
- DAX
- Microsoft Excel
- Data Visualization
- Data Analysis

## 💡 Key Insights

The dashboard provides an interactive view of collection performance and helps identify trends across states, executives, repayment status, and monthly collections.
